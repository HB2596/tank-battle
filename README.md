# 坦克大战 Tank Battle

HTML5 Canvas 实现的经典坦克大战游戏，无需任何外部依赖。

## 玩法
- **WASD** 或 **方向键** 移动坦克
- **空格键** 射击
- 消灭所有敌方坦克进入下一波
- 随着波次提升，敌人数量和种类会增加

## 敌人类型
| 类型 | 颜色 | 速度 | 血量 | 分数 |
|------|------|------|------|------|
| 普通 Basic | 红色 | 标准 | 1 | 10 |
| 快速 Fast | 橙色 | 快 | 1 | 20 |
| 重装 Heavy | 紫色 | 慢 | 2 | 30 |

## 运行
直接用浏览器打开 `index.html` 即可游玩。

## 技术
- 原生 HTML5 Canvas + JavaScript
- 零依赖，单文件部署
